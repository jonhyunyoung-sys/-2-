# ⚡ Gimkit Web (실시간 퀴즈 & 머니 배틀 게임)

Gimkit(김킷)의 독창적인 게임 시스템(자율 퀴즈 풀이, 상점 업그레이드, 머니 경제, 파워업 공격 및 실시간 리더보드)을 그대로 구현한 웹 애플리케이션입니다.

---

## 🌟 핵심 특징

1. **🧗 Don't Look Down (1,000m 등반 파쿠르 모드)**
   - Gimkit 최고의 인기 2D 점프 액션 모드를 완벽 재현!
   - 0m에서 1,000m 정상(Peak)까지 수직으로 솟은 산을 오르는 파쿠르 레이스
   - **에너지 시스템**: 점프와 더블 점프 시 에너지가 소모되며, `[Q]`를 눌러 퀴즈를 맞히면 대량의 에너지가 충전됩니다.
   - **추락 페널티 (Don't Look Down!)**: 헛디디면 아래로 아찔하게 곤두박질치며, 화면 흔들림과 비명 연출이 발생합니다.
   - **6개 테마 서밋 (Summits 1~6)**:
     - 🌋 Summit 1 (0m~200m): Emberwall Ascent (화산 벽돌)
     - 🪸 Summit 2 (201m~350m): Coral Climb (산호초 발판)
     - 🕵️ Summit 3 (351m~500m): Agent Adventure (수평 이동 발판)
     - 🍄 Summit 4 (501m~680m): Growing Up (고탄력 버섯 스프링 점프대)
     - ❄️ Summit 5 (681m~850m): Frosty Peaks (미끄러운 얼음 블록)
     - 🚀 Summit 6 (851m~999m): One Way Up (점멸하는 레이저 장벽)
     - 🏆 1,000m Peak: 황금 정상 제단 및 최종 우승 시상대!
   - **실시간 멀티플레이어 고스트**: 다른 친구들과 AI 봇들이 함께 등반하는 모습을 실시간으로 보며 경쟁합니다.

2. **Gimkit 스타일 자율 퀴즈 (Classic Money Battle)**
   - 다른 참가자를 기다릴 필요 없이 각자의 속도로 문제를 풀고 정답을 맞혀 머니($)를 획득합니다.
   - 연승(Streak)에 따른 보너스 및 수익 배율이 실시간으로 적용됩니다.

2. **상점 & 수익 업그레이드 (The Shop)**
   - **문제당 머니 (Money Per Question)**: Level 1($1)부터 시작하여 최대 수만 달러까지 기본 보상 인상
   - **연승 보너스 (Streak Bonus)**: 연속 정답 시 추가 보너스 적립
   - **수익 배율 (Multiplier)**: 1.5배, 2.0배, 3.0배 ... 최대 10배 승수
   - **오답 손실 보험 (Insurance)**: 오답 시 차감되는 손실 방어 (50%, 80%, 100% 면책)

3. **파워업 & 견제 아이템 (Power-Ups)**
   - 🧊 **얼리기 (Freeze)**: 1등이나 경쟁 상대를 12초 동안 얼려 문제 풀기를 마비시킵니다.
   - 🛡️ **방어막 (Shield)**: 상대방의 공격(얼리기 등)을 1회 완벽하게 방어합니다.
   - 🎰 **메가 복권 (Mega Lottery)**: 50% 확률로 자산 2배 대박 찬스 (실패 시 25% 손실)
   - ⚡ **전파 방해 (EMP)**: 모든 상대의 화면을 노이즈와 글리치로 6초간 방해합니다.
   - 🎁 **머니 선물 (Gift)**: 친구에게 머니 선물하기

4. **호스트 대형 스크린 (Big Screen / Projector View)**
   - 참가자 대기실(Lobby), 실시간 방 번호(`311866`) 표시
   - 시간 제한 모드(3분~15분) 또는 목표 금액 레이스($3,000 ~ $100,000) 지원
   - 실시간 순위 변동 애니메이션과 실시간 이벤트 티커("🔥 홍길동님이 5연속 정답!", "🧊 영희님이 민수님을 얼렸습니다!")
   - 게임 종료 시 3D 스타일 시상대(Podium) & 컨페티(폭죽) 축하 연출

5. **가상 AI 봇 & 솔로 모드 지원**
   - 혼자서도 즉시 플레이할 수 있도록 AI 봇(스마트봇, 알파고, 번개토끼 등) 대결 기능 제공
   - AI 봇들은 스스로 문제를 풀고, 상점에서 업그레이드를 구매하며, 상위 플레이어에게 얼리기를 사용하는 지능적인 로직 탑재

6. **Web Audio 내장 사운드 엔진**
   - 외부 오디오 파일 다운로드 없이 브라우저 자체 오디오 신디사이저로 정답음, 오답음, 코인음, 빙결음, 팡파레 음악을 100% 재생 (음소거 버튼 지원)

## 🚀 빠른 실행 방법

### 1. 패키지 설치 및 서버 구동
```bash
cd /Users/hyeon-yeong/gimkit-app
npm start
```

### 2. 접속 주소
- 🏠 **메인 포털**: `http://localhost:3000`
- 👑 **호스트(대형 화면)**: `http://localhost:3000/host.html`
- 🎮 **플레이어 참가 (링크 접속)**: `http://localhost:3000/join?gc=311866`

## 📁 프로젝트 구조

```
gimkit-app/
├── package.json          # Node.js 프로젝트 설정 및 의존성 (express, socket.io)
├── server.js             # 웹소켓 게임 서버, 방 관리, AI 봇 루프, 상점 및 전투 엔진
├── questions.json        # 퀴즈 데이터셋 (상식, 개발/IT, 게임/문화 등)
├── README.md             # 안내 문서
└── public/
    ├── index.html        # 메인 진입 포털 (참가, 호스트, 솔로 즉시 플레이)
    ├── host.html         # 호스트 대형 스크린 화면 (대기실, 실시간 순위, 시상대)
    ├── play.html         # 플레이어 전용 화면 (퀴즈, 상점, 파워업, 피격 연출)
    ├── style.css         # Gimkit 스타일의 네온/다크 테마 및 반응형 CSS
    └── js/
        ├── sound.js      # Web Audio API 사운드 신디사이저
        ├── host.js       # 호스트 클라이언트 로직
        └── player.js     # 플레이어 클라이언트 로직
```
